أبني أنظمة مؤسساتية وتطبيقات موبايل حديثة — من ASP.NET و Angular إلى Flutter و Firebase — مع تركيز على حلول واضحة وقابلة للتوسع.

نبذة عني

مهندس معلوماتية ومطور ويب شامل متخصص في Angular و ASP.NET Core، مع خبرة عملية في تصميم الأنظمة الأساسية وأنماط مثل CQRS و MediatR. أعمل حالياً على أنظمة التحول الرقمي في المؤسسة العامة للخطوط الحديدية السورية، وأستخدم SQL Server و PostgreSQL و Docker لبناء بيئات تطوير ونشر حديثة. حديثاً وسّعت خبرتي نحو Flutter و Firebase (Firestore، Authentication، Cloud Functions) وإدارة الحالة وواجهات API، ضمن أعمال تعاونية مع وكلاء Cursor لبناء تطبيقات موبايل وخدمات سحابية.

Flutter و Firebase

مطور تطبيقات
