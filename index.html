شهادات ودورات

نبذة عني

مهندس معلوماتية ومطور ويب شامل (Full-Stack) متخصص في Angular و ASP.NET Core. أمتلك خبرة عملية قوية في تصميم وتطوير الأنظمة البرمجية الأساسية، وتطبيق أنماط التصميم المتقدمة مثل CQRS و MediatR. أعمل حالياً على تطوير أنظمة التحول الرقمي في المؤسسة العامة للخطوط الحديدية السورية، ولدي شغف دائم بتعلم تقنيات الويب الحديثة وتصميم واجهات مستخدم استثنائية. أعمل مع قواعد بيانات SQL Server و PostgreSQL، وأتقن التعامل مع حاويات Docker (Docker & Docker Compose) لبناء بيئات تطوير ونشر حديثة على جميع الأنظمة (Windows, Linux, Cloud). حديثاً وسّعت خبرتي نحو Flutter و Firebase (Firestore، Authentication، Cloud Functions) وإدارة الحالة وواجهات API، ضمن أعمال تعاونية مع وكلاء Cursor.
